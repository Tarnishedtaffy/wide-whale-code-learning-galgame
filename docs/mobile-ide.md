# Whale Studio 移动 IDE 前端

本分支新增一个零依赖、纯浏览器运行的 IDE 工作台。根页面跳转到 `ide.html`；原有 `mobile.html` 学习页面保留。

## 运行

直接打开 `ide.html`，或在仓库根目录启动静态服务：

```powershell
py -3 -m http.server 8768 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8768/`。页面直接响应浏览器尺寸变化；旧入口 `docs/ide-preview.html` 自动跳转到同一个工作台，不再提供尺寸工具栏。

## 界面和交互

- 手机和平板（宽度 ≤ 900px）：三张全高工作卡横向滚动，CSS Scroll Snap 吸附；默认中间编辑器。左右滑动或底部导航切换。
- 桌面：左文件管理器、中编辑器和下方终端、右助手面板并排。
- 移除工作台顶部品牌、介绍和项目装饰区，让工作卡填满可用高度。运行按钮改为终端标题栏清空键旁的高亮 ▶，保留键盘快捷键和辅助标签。
- 文件：文件名搜索、目录折叠、新建文件、点击打开、当前文件导出。
- 编辑器：多文件标签、基础词法高亮、行号、光标位置、Tab 插入四个空格、自动保存。Ctrl / Cmd + S 保存；Ctrl / Cmd + Enter 运行演示。
- 终端：可折叠、清空；支持 `help`、`ls`、`cat 文件名`、`python 文件名`、`clear`。
- 助手：预设演示问答与当前文件上下文；不再使用二级标签。右侧露出三张扇形展开的扑克牌角，点击或停留在助手页后继续向左划，呼出悬浮的知识卡牌。卡组沿用 90% 宽度的定位区域，去掉外层容器的背景、边框、阴影和标题区，直接悬浮于聊天上。
- 卡牌：单张阅读、底下两张错位层叠。卡上左划下一张、右划上一张，首尾循环；点击卡牌沿用原 `mobile.html` 的 0.55 秒 3D 翻面；拖动跟手倾斜、松开发牌、底牌上浮，短距离拖动回弹。也可用键盘方向键。保留每张的翻面状态。展开后不显示下方提示、页码、探索进度或切页按钮，关闭按钮在牌面右上角；卡序仅向屏幕阅读器播报。
- 收起：卡牌外向右划、点击背景/关闭按钮或 Esc 收起；卡上右划只切换上一张，不会误收起。聊天内容、草稿和阅读位置保留。收起后再向右划返回编辑器。卡组打开时限制键盘焦点在内部，收起后恢复入口焦点；非当前卡不进入 Tab 顺序。尊重减少动态效果设置。

## 边界

无服务端、无真实 Shell、无模型 API。Python 仅包含受限的前端演示解析器：字符串、数字、变量赋值、同类型 `+`、`print()`；不支持完整 Python、包、文件系统、网络和进程。未使用 `eval` 或动态函数执行用户代码。

文件内容存于当前源的 localStorage（键 `whale-studio-workspace-v1`），刷新可恢复。浏览器清理数据会删除这些文件；存储不可用时界面会提示导出。文件导出只下载当前文件。AI 对话与卡片探索进度仅保留在本次页面会话。

使用系统字体，无 CDN、外部素材或构建依赖。适配动态视口高度、移动端安全区、减少动态效果设置；实际手机键盘和系统手势仍需真机验证。
